# Upgrade 1.1.0

Date: 2026-08-03

## Added

- Work modes for page, template sample, site inventory, incident, migration, and AI-search extension.
- Coverage ledger and risk-based sampling guidance.
- Static-response versus rendered-DOM evidence separation.
- Rerun manifest and three-stage change verification.
- Current Google AI-features boundary plus provider-specific AI-search observation.
- Machine-readable SEO audit schema, semantic validator, fixture, and tests.
- Trigger/output cases for AI Search, JavaScript rendering, migration, large sites, scaled content, and traffic-drop causality.

- Expanded the workflow from checklist execution to reproducible evidence collection.

## Compatibility

- Existing audit, keyword research, and implementation requests remain supported.
- The machine-readable audit contract starts at schema version `1.0` and is additive to the Markdown output.
