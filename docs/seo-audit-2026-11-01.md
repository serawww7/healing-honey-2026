# Technical SEO audit — healing-honey.pp.ua

**Date:** 2026-11-01  
**Skill:** qiaomu-seo (joeseesun/qiaomu-seo)  
**Work mode:** site inventory + template sample + implementation  
**Evidence modes:** code, rendered (`public/`), live HTTP HEAD/GET  
**Engines/surfaces:** Google & Bing organic (AI search: foundational crawl/index only)  
**Action:** fix authorized by user without per-item approval

## Executive summary (top 3)

1. **Metadata / social / schema were broken or generic** — empty `og:description`, wrong `og:type`, no `og:image`, Blog JSON-LD on every URL. Fixed in `head.html`.
2. **Indexability pollution** — `/search/` and `/404/` were indexable and in sitemap; real `404.html` was missing. Fixed with `noindex`, robots, sitemap exclusions, project `layouts/404.html`.
3. **Canonical & duplication** — paginated `/page/N/` all canonicalized to `/`; near-duplicate articles shared titles. Fixed self-canonicals + unique titles / cross-canonicals.
